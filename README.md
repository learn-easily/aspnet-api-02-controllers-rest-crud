# ლექცია 2 — Minimal API vs Controller · REST · CRUD · Swagger

ანიმაციური HTML პრეზენტაცია + ლექტორის სცენარი.

| ფაილი | რა არის |
|---|---|
| `index.html` | პრეზენტაცია (42 სლაიდი) |
| `script.html` | ლექციის სცენარი — წასაკითხად / დასაბეჭდად |
| `deck/` | წყარო: სლაიდები და შენიშვნები (`l2.html`), ძრავი (`engine.*`), ბილდი (`build_l2.py`) |

## გამოყენება

1. გახსენი `index.html` Chrome-ში ან Edge-ში, გადაიტანე პროექტორზე, დააჭირე `F`.
2. დააჭირე `Ctrl+Shift+P` — გაიხსნება **ლექტორის ფანჯარა** სცენარით.
3. ნავიგაცია **მხოლოდ ისრებით**: `→` შემდეგი, `←` წინა (`Shift+→` — შემდეგი სლაიდი). Space, Enter, მაუსის დაჭერა და swipe გამორთულია.

სხვა კლავიშები: `N` შენიშვნები · `O` ყველა სლაიდი · `A` სლაიდის ყველა ნაბიჯი.

## ცვლილების შეტანა

```bash
cd deck && pip install pygments && python3 build_l2.py
cp ../out/index.html ../index.html && cp ../out/script.html ../script.html
```
